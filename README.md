# GORGONA — графіка сервера

Сховище графічних ресурсів сервера GORGONA. Власник проєкту: MED.
Репозиторій належить GitHub-акаунту `oteckr`:
https://github.com/oteckr/gorgona-server-assets

## Структура

- `assets/backgrounds/` — фонові зображення меню.
- `assets/logos/` — логотипи сервера.
- `assets/buttons/` — графіка кнопок і розділів.
- `assets/cases/` — зображення кейсів.
- `assets/icons/` — піктограми інтерфейсу.
- `references/` — дозволені до публікації візуальні орієнтири.

## Підключення до Battlepass

Завантажені зображення можна підключати прямими посиланнями в наявній
конфігурації Battlepass: `Background`, `Logo`, зображення розділів та кейсів.

Коли репозиторій буде опубліковано, для кожного готового зображення потрібно
перевірити відкриття його прямого посилання без авторизації. Посилання має
віддавати файл зображення, а не вебсторінку перегляду репозиторію.

## Підготовка зображень

Назви файлів — латиницею, малими літерами, без пробілів. Нові редакції мають
окремі назви, наприклад `background-main-v1.png` та `background-main-v2.png`.
Це дозволяє зберегти попередню графіку й явно перемикати версію в конфігурації.

Фони готуються з урахуванням розміщення тексту меню, логотипа, таблиць та
кнопок. Написи інтерфейсу залишаються українською мовою. Прозорі логотипи
та піктограми зберігаються у PNG.

## Стан підготовки

Репозиторій створено для довгострокового зберігання графіки сервера.
Початкові папки готові; зображення додаються після узгодження опису.
