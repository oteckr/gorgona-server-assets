# ЇРЖА — зображення наборів Kits

Тут зберігаються затверджені власником мініатюри для ігрового меню Rust Kits.

- `manifest.json` пов’язує точну назву набору з файлом, прямим HTTPS URL, розмірами та SHA-256.
- `start-pvp-v1.jpg` — затверджений StartPVP, 512×512, RGB baseline JPEG, 54 466 байтів.
- Нове оформлення отримує нову назву (`-v2`, `-v3`), щоб уникати плутанини кешу. Затверджені версії не перезаписуються.
- У `KitImage` потрібен прямий URL `raw.githubusercontent.com`, а не сторінка GitHub із `/blob/`.
- Для серверного пакета URL фіксується на SHA коміту; `main` у каталозі — зручна адреса перегляду.
- Kits використовує ImageLibrary. ImageLibrary завантажує JPG, перекодовує у PNG і передає з файлового сховища Rust. JPG тут зменшує початкове завантаження; обсяг клієнтського PNG може бути більшим.
- Спочатку завантажте ImageLibrary, потім Kits. Після зміни KitImage виконайте `oxide.reload Kits`, дочекайтеся завершення імпорту й заново відкрийте `/kit`.
- Публічний репозиторій містить лише зображення та їх каталог. Дані гравців, замовлення й серверні секрети сюди не додаються.

Джерела візуальних референсів StartPVP: скриншот одягу від власника та офіційні рендери предметів із Rust Wiki / files.facepunch.com (bow.hunting, arrow.wooden, bandage, pumpkin). Фінальна композиція створена за цими референсами.

## Фірмові елементи інтерфейсу

- `irzha-logo-v1.png` — оригінальний логотип ЇРЖА, прозорий PNG.
- `default-kit-v1.png` — загальне зображення набору в стилі ЇРЖІ, 512×512.
- `view-kit-v1.png` — прозорий значок перегляду, 128×128.

Їхні ключі ImageLibrary та SHA-256 наведені в `manifest.json`. Локалізований плагін і серверні налаштування зберігаються окремо від цього публічного каталогу зображень.
